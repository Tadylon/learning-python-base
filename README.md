this is a repo to learning python base

this project contains examples and exercises for learning the basics of Python programming.

the project is organized into different modules, each focusing on a specific aspect of Python programming, such as data types, control flow, functions, and more.

the environment for this project is conda
there is a requirements.txt file in the root directory of the project that lists all the dependencies required to run the code in this project. You can use this file to create a virtual environment and install the necessary packages.
